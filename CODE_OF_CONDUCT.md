# Code of conduct

Be direct, constructive, and respectful.

- Discuss the work, not the person's identity or motives.
- Assume incomplete context before assuming bad intent.
- Give reproducible evidence for technical claims.
- Accept correction and update the record when evidence changes.
- Do not publish another person's credentials, documents, diagnostics, or private
  device and network information.
- Harassment, threats, discrimination, sexualized conduct, and sustained personal
  attacks are not welcome.

Maintainers may edit or remove harmful content and restrict participation when
needed to keep the project usable and safe. Report conduct concerns privately
through the repository maintainer's GitHub profile or, when security is involved,
the process in [SECURITY.md](SECURITY.md).
