## Work implemented

- Added strict, versioned, current-user profile storage and private OpenSSH
  files with fail-closed ownership, permissions, link, size and schema checks.
- Added direct-cable-bound Ed25519 host acquisition behind service-label,
  live-device, and post-acquisition tablet-identity gates.
- Added generation-owned process launch, tombstoning, bounded retirement,
  retryable ownership and stale-publication rejection.
- Preserved the no-false-`Live` reducer: authenticated transport alone is not a
  frame and input session.
- Kept setup Mac-local and stopped before installing a public key on the tablet.
- Narrowed that checkpoint's display endpoints to `482 x 877` compact and
  `802 x 877` Files-open. The formula uses visible-height-minus-72 clamped to
  `720...1040`, compact width at height times `0.55` clamped to `440...590`,
  and a 320-point Files pane.
- Reworked visible copy and semantic typography so status reads as plain
  metadata, `USB‑C` and `Wi‑Fi` stay together, and recovery content fits.
- Kept `Touch + Type` and `Pen` as adjacent one-click segments through
  Accessibility 3 and removed the circular container from the Files folder
  icon.
