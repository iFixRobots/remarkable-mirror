This checkpoint records implemented source, a product-only build and the final
local Release-package comparison. It is not physical-tablet,

## Implemented

- One non-resizable tablet-proportioned Mac window: `456 x 877` compact and
  `776 x 877` Files-open. Files moves programmatically only between those
  widths. Its animation was accepted as smooth. Default-size visual fitting and
  source inspection are complete; this is not owner acceptance.
- Files refresh starts only after the opening endpoint, notice lifetimes follow
  severity, and the pane has a native circular close action while the toolbar
  folder remains plain.
- **Add This Mac…** finalization behind repeated exact direct-cable gates. The
  confirmed action appends the dedicated public key and installs the USB
  keep-awake service. Its one-time root password is never saved, and it does not
  configure Wi-Fi, change documents, or change the Wi-Fi password.
- Durable pending-authorization, pending-Wi-Fi and ready pairing states.
  **Connection > Set Up Wi-Fi…** resumes the separate pending Wi-Fi step after
  an interruption without repeating the public-key append.
- Protected Keychain storage for the paired Wi-Fi context secret and wake token.
  Service-scoped deletion precedes local profile reset.
- Owner-started USB-C and Wi-Fi connections with exact binding checks. One
  **Connect USB-C** click owns bounded same-cable wake, recovery,
  authentication, and connection without selecting or falling back to Wi-Fi.
- Generation-owned frame, input, Files, wake and recovery work. Retirement,
  cancellation and stale-publication checks preserve the rule that **Live**
  needs a fresh frame and ready input session from one current generation.
- Direct-USB wake handling, capability refresh, interrupted-setup recovery and
  app-owned reset cleanup. Local reset intentionally does not remove the
  tablet-side authorized key or disable Developer Mode Wi-Fi SSH.
- Fixed-name, payload-free Points of Interest intervals cover connection activation,
  first-frame delivery, screenshot encoding and Finder promise fulfillment.

## Local validation

The stable Debug build command pattern is:

```zsh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild \
  -project mirror/macos/ReMarkableMirror.xcodeproj \
  -scheme ReMarkableMirror \
  -configuration Debug \
  -derivedDataPath /tmp/rmm-compile-check \
  CODE_SIGNING_ALLOWED=NO \
  build
```

- The source builds as a single production target under stable Xcode 26.6.
- Shared `go test ./...`, `go vet ./...` and host-policy checks pass.

  `e788dab5d24e7a03ddc0746f37e0077dc5f2b0c64bd8154ad9214a9711eb7eb1`.
  A fresh extraction matched the Release product recursively.
- No validation in this checkpoint contacted or changed a tablet.
