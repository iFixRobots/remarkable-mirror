# Support

Use [GitHub Issues](https://github.com/iFixRobots/remarkable-mirror/issues) for
reproducible bugs and focused feature requests.

## Supported surfaces

- **Windows 11 x64:** native WinUI app with the complete installer/setup path.
- **macOS on Apple silicon:** native SwiftUI/AppKit app; current development
  builds are unsigned.
- **Tablet components:** ARM64 Linux helpers that run on the reMarkable and
  support both desktop apps. There is no Linux desktop host.

Read [Platform support](docs/PLATFORM_SUPPORT.md) before filing a platform or
installation report.

## Before filing

1. read [Getting started](docs/GETTING_STARTED.md) and
   [Troubleshooting](docs/TROUBLESHOOTING.md);
2. retry the exact manual action that failed; Mirror does not choose, fall back,
   or reconnect a route automatically;
3. record the host OS and version, Mirror version, and package source (release,
   Actions run, or local commit/build);
4. record the tablet model and firmware version; and
5. name the selected route (USB-C or Wi-Fi) and whether the tablet was awake and
   unlocked.

Review all text, screenshots, and diagnostics before posting. Remove
credentials, keys, tokens, document contents and filenames, IP addresses,
personal network details, and unrelated device identifiers. Do not attach raw
logs unless you have reviewed every line.

Security issues belong in the private channel described by
[SECURITY.md](SECURITY.md).

This community project cannot provide reMarkable warranty, account, cloud, or
hardware support. Contact reMarkable for those products and services.
